# 📊 ABC Company Employee Analysis

Python | Pandas | NumPy | Matplotlib | Seaborn

---

# 📌 Project Overview

This project analyzes employee data from ABC Company using Python. The dataset contains details such as team, position, age, salary, and height. The objective of the project is to preprocess the data, perform analysis, visualize important patterns, and derive meaningful insights.

---

# 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab Notebook

---

# 🧹 Data Preprocessing

The following preprocessing steps were performed:

✅ Loaded the dataset using Pandas  
✅ Checked dataset information and missing values  
✅ Corrected the `Height` column by replacing values with random numbers between 150 and 180  
✅ Created age groups for analysis

# 🔍 Key Insights

- Employee distribution across teams is relatively balanced
- Most employees belong to SG and PF positions
- Majority of employees fall within the 19–30 age group
- Certain teams and positions have significantly higher salary expenditure
- Age and salary show a weak positive correlation
